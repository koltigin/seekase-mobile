# Seekase — CLOCK IN demo script

Target length: 2–3 minutes. Record the final standalone APK on a physical Seeker with no Metro connection and no private notifications visible.

## Before recording

- Use a dedicated demo account with safe public profile data.
- Confirm the wallet address, signatures, email address, RPC key, and Supabase identifiers never appear on screen.
- Prepare one polished collection with three visually distinct items and complete metadata.
- Prepare a second account or seeded public content for social actions.
- Confirm the daily check-in is available for the current UTC day.
- Disable unrelated notifications and enable Do Not Disturb.
- Use English device/app UI for a consistent submission.

## Shot list

### 0:00–0:15 — Problem and promise

Voiceover: “Collectors keep meaningful objects, but their stories are scattered across camera rolls, spreadsheets, and marketplace listings. Seekase gives every collection a place.”

Show: Seekase launch and one onboarding slide.

### 0:15–0:35 — Seeker-first entry

Show: choose Solana wallet, open Seed Vault, approve SIWS, return to Seekase.

Voiceover: “On Seeker, collectors enter with the wallet already on their phone. Wallet ownership stays private and separate from the public profile.”

Do not pause on approval details long enough to reveal identifiers.

### 0:35–1:05 — Build a collection

Show: Add → choose category → name collection → add item → select photo → add category-specific metadata → save.

Voiceover: “Seekase supports broad collection categories and adapts the form to the object: a book has an author and publisher; other categories use their own relevant details.”

### 1:05–1:30 — Discovery and social loop

Show: Discover feed → open public collection → like/save/comment → open collector profile → follow.

Voiceover: “Collectors discover new cabinets and the people behind them, then follow, like, save, and comment without turning the experience into a marketplace.”

### 1:30–1:55 — Seeker identity

Show: own Profile → Wallet Verified → Seeker Genesis badge.

Voiceover: “Seekase checks genuine Seeker Genesis eligibility on the backend. The public sees a derived badge, while wallet and token details remain private.”

### 1:55–2:20 — Mainnet daily check-in

Show: Daily Check-in → explicit button press → Seed Vault transaction approval → return → updated streak.

Voiceover: “A daily Mainnet Memo check-in gives Seeker collectors a recurring streak. Seekase charges no fee; the wallet shows and approves the network fee.”

Use one real approved transaction. Never edit the video to imply a transaction succeeded if it did not.

### 2:20–2:35 — Close

Show: profile collections grid, then Seekase wordmark and `seekase.app`.

Voiceover: “Seekase is the trusted global home for the objects people choose to keep.”

## Capture checklist

- Wallet return works without a development menu.
- Collection and image remain after a cold restart.
- Public content appears after refresh.
- SGT badge is genuine and current.
- Check-in streak updates after server verification.
- No loading errors, placeholder copy, debug overlays, or private values appear.
- Export at 1080p or higher with readable UI and clear audio.
