# CLOCK IN submission copy

## Project name

Seekase

## One-line description

A Seeker-first social showcase where collectors build personal museums, preserve the stories behind their objects, and discover other collectors.

## Short description

Seekase turns personal collections into living, image-led cabinets. Collectors document objects with category-specific details, share public collections, discover people with similar interests, and interact through follows, likes, saves, comments, and private conversations. Solana Mobile Wallet Adapter provides Seeker-first account entry, while genuine SGT eligibility and Mainnet check-in streaks add verifiable participation without exposing wallet addresses or token data on public profiles.

## Problem

Collectors currently split their objects and stories across camera rolls, spreadsheets, marketplace listings, and general social networks. Those tools optimize for storage, selling, or broad posting rather than context, provenance, collector identity, and discovery.

## Solution

Seekase gives each collection a cabinet and each object a structured story. It supports open-ended categories, photo-led presentation, collector profiles, social discovery, moderation, private messaging, and clear separation between the Seekase account, wallet identity, and public profile.

## Solana Mobile integration

- Mobile Wallet Adapter and Sign In With Solana for Seeker-first entry.
- Private proof of wallet control, separated from the public collector profile.
- Genuine Mainnet Seeker Genesis Token verification through a private backend adapter.
- Explicitly approved Mainnet Memo daily check-ins with streak achievements.
- No custody, checkout, token transfer, or hidden application fee.

## Why users return

Collectors return to document new finds, improve existing records, follow evolving cabinets, discuss objects with knowledgeable people, and maintain check-in and collection milestones.
